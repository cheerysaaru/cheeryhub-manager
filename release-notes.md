## Cheeryhub Desktop v1.0.0

Electron wrapper for the Cheeryhub web app (https://cheeryhub.space).

### ⚠️ Important
- **Unsigned installer**: Windows SmartScreen will show a warning ('Windows protected your PC'). Click 'More info' → 'Run anyway'.
- Requires internet connection and a Cheeryhub account (sign up at https://cheeryhub.space).
- Loads the live web app; cookies persist between restarts.

### What's included
- Native Windows installer (NSIS) with choose-your-folder option
- Auto-updates via GitHub Releases (when published)
- Shortcuts in Start Menu and Desktop

### System requirements
- Windows 10/11 (64-bit)
- Internet connection
