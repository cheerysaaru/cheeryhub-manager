## Cheeryhub Desktop v1.0.1

Electron wrapper for the Cheeryhub web app (https://cheeryhub.space).

### ⚠️ Important
- **Unsigned installer**: Windows SmartScreen will show a warning ('Windows protected your PC'). Click 'More info' → 'Run anyway'.
- Requires internet connection and a Cheeryhub account (sign up at https://cheeryhub.space).
- Loads the live web app; cookies persist between restarts.

### What's new in v1.0.1
- Added classic NSIS installer with welcome page, folder picker, progress page, and finish page
- Finish page includes "Launch Cheeryhub" checkbox
- Desktop and Start Menu shortcuts created
- Proper uninstaller included

### What's included
- Native Windows installer (NSIS) with welcome page, folder picker, progress page, and finish page
- "Launch Cheeryhub" checkbox on finish page
- Desktop and Start Menu shortcuts
- Proper uninstaller

### System requirements
- Windows 10/11 (64-bit)
- Internet connection
